# Rebellions

> Rebellions is an AI infrastructure company building energy-efficient AI inference hardware (NPUs) and the software stack to deploy large language and multimodal models on it at scale. Products include the Rebel100 inference chip, ATOM-Max Server/POD, and RebelServer. The RBLN SDK compiles and serves HuggingFace, PyTorch, and TensorFlow models on RBLN accelerators. Rebellions is not a REST/HTTP API provider; developers integrate via Python SDKs and serving frameworks (vLLM, Triton, TorchServe, Kubernetes).

## Packages

- [optimum-rbln (PyPI)](https://pypi.org/project/optimum-rbln/): HuggingFace Transformers/Diffusers interface for RBLN accelerators. `pip install optimum-rbln`
- [vllm-rbln (PyPI)](https://pypi.org/project/vllm-rbln/): vLLM plugin for RBLN NPU. `pip install vllm-rbln`
